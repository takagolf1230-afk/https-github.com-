# SNSアカウント設計（Instagram / X）

目的: 医療職に**調査への回答**をしてもらい、のちに**先行販売**の案内を届けられる土台を作る。
※「アカウント設計」はSNSアカウントのことと解釈して作成しました。ソフトの利用者アカウント（ログイン機能）のことなら、別途設計します。

## 0. ターゲット設計（確定: 若手の技師・看護師 / 管理職 / コメディカル）

同じ「医療職」でも、**使う人**と**買う人**が違います。ここを分けて設計します。

| 層 | 役割 | 困りごと（仮説・調査で検証） | 届け方 | 求めること |
|---|---|---|---|---|
| 若手の技師・看護師 | **使う人／声を出す人** | 記録・書類、申し送り、先輩の分の雑務、勉強会の準備 | X・Instagram（日常的に見る） | 回答、拡散、先行案内の登録 |
| 管理職（主任・師長・技師長など） | **決める人／買う人** | 勤務表・当番づくり、人員調整、スタッフの残業、施設への説明 | Xの交流、聞き取り、紹介（若手経由で紹介を依頼） | 聞き取り、施設での導入判断 |
| コメディカル（技師・薬剤師・PT/OT/ST・臨床工学技士など） | 職種を広げた**需要確認** | 職種ごとに異なる（勤務表・当番は共通しやすい） | ハッシュタグ・職種別の投稿 | 回答（どの雑務が共通か） |

ポイント
- **SNSで広く集まるのは若手**。管理職はSNSの回答が少なくなりやすいので、**別ルート**（聞き取り・紹介）を用意する。
- 売る相手は、個人（若手）より**施設・部署（管理職）**になる可能性が高い。調査で「誰が払うか」を必ず確認する。
- 「コメディカル」は医師・看護師以外の医療職を指すことが多い。看護師は別枠で書かれることもあるため、投稿では職種を並べて書く。
- 職種を広げすぎると訴求がぼやける。**最初の投稿の主役は「勤務表・当番・申し送り」など共通の雑務**にして、職種別の違いは回答後に分ける。

### 層ごとのメッセージ例
- 若手: 「先輩に聞きにくい雑務、ありませんか？ 1分アンケート」
- 管理職: 「勤務表づくりや人員調整に、毎月どれくらい時間をかけていますか？ 現場責任者の方の声を聞かせてください」
- コメディカル: 「技師・薬剤師・リハビリ職・臨床工学技士のみなさん。職種をこえて共通の雑務を探しています」

## 1. 基本方針
| 項目 | 方針 |
|---|---|
| 役割分担 | **X = 調査の入口・拡散・交流**、**Instagram = 信頼づくり・見せる場（画面・図解）** |
| 個人との関係 | 本名・勤務先の個人アカウントとは**分ける**。ソフト開発用のアカウントを新設する |
| 発信する立場 | 「現場の雑務を減らすソフトを作っている人」。医療職（現場経験）であることは、事実の範囲で書く |
| 約束すること | 患者情報は扱わない / 勤務先を特定させない / 調査結果は共有する |
| 避けること | 患者さんの話、勤務先・同僚の特定につながる投稿、誇大な効果の主張 |

## 2. 名前・ID・プロフィール

### 名前とID（例。実際に空いているものを選ぶ）
- 表示名の型: `【雑務ラボ】医療職の時短ソフト`（Xは日本語、Instagramは短く）
- ID（半角英数）の型: `zatsumu_lab_med` のように、**XとInstagramで同じ文字列**にそろえる
- 避ける: 病院名・個人名・資格名そのもの（例: `radtech_taro`）。商標や既存サービスと紛らわしい名前は使わない
- 使う前に: 同名の検索、商標・屋号の確認、ドメインの空きを見る（将来サイトを持つ場合）

### アイコン・ヘッダー
- アイコン: シンプルな図形ロゴ（人物の顔写真は不要）。XとInstagramで同一にする
- ヘッダー（X）: 「医療職の雑務を減らすソフトを作っています／1分アンケート実施中」＋色は2色まで

### プロフィール文（案）
**X（160字以内）**
```
医療現場の「雑務」を減らすソフトを作っています。
勤務表・申し送り・記録…どれが一番つらい？ 1分・匿名アンケート実施中↓
※患者情報は扱いません／結果は共有します
```
**Instagram（150字以内）**
```
医療職の雑務を減らすソフト開発🩻
アンケートの結果・開発の様子を発信
👇1分・匿名アンケート（リンクから）
```
- リンク: 調査フォームのURLを設定。先行販売の段階になったら、説明ページ（`presale_page.md`）に切り替える
- 「医療従事者です」と書く場合は、事実の範囲で。資格・所属を偽らない（職種の記載は任意）

## 3. 発信の柱（コンテンツの型）
| 柱 | 内容 | 主な媒体 | 目的 |
|---|---|---|---|
| ① 共感 | 現場あるある（雑務の悩み）を短く | X / IG | 見つけてもらう・共感 |
| ② 調査 | アンケートの案内・途中経過・結果 | X / IG | 回答を集める |
| ③ 見せる | 試作の画面・動画・Before/After（ダミーデータ） | IG（リール） | 「欲しい」を引き出す |
| ④ 学び | 勤務表づくりのコツ、Excel小技など | X / IG | フォロワーに役立つ価値を渡す |
| ⑤ 案内 | 先行販売・先行案内の登録 | X / IG | 収益化 |

配分の目安: 共感4 / 調査2 / 見せる2 / 学び2（案内は先行販売の段階から）

## 4. 投稿頻度（無理なく続ける）
| 媒体 | 頻度 | 備考 |
|---|---|---|
| X | 平日1日1〜2投稿＋返信 | 返信・引用で交流する（フォロワー数よりも、同業者の目に触れることを優先） |
| Instagram | 週2〜3回（フィード/リール）＋ストーリーズ随時 | 画像は共通テンプレートを作り、制作を軽くする |
- 続かないなら減らす。Xを主力にして、Instagramは週1から始めてもよい。

## 5. 最初の30日の計画
| 期間 | やること | 完了の目安 |
|---|---|---|
| 準備（〜0日） | 名前・ID決定、両アカウント作成、プロフィール・アイコン設定、調査フォーム公開 | フォームから回答テストが通る |
| 1週目 | 共感投稿を5〜7本。同業者アカウントをフォローし、返信で交流 | フォロワー数より、反応（返信・保存）を見る |
| 2週目 | 調査の案内を開始（`sns_posts.md` の案A） | 回答20件 |
| 3週目 | 案B・案Cで再投稿。途中経過（回答数）を共有 | 回答50件 |
| 4週目 | 速報を投稿（上位の雑務）。聞き取りの協力者を募る | 聞き取り5名の約束 |
- 数字は目安であり、実績の保証ではありません。回答が少なければ、文面・時間帯・ハッシュタグを変えて再投稿します。

## 6. 指標（見る数字）
| 指標 | 見る理由 |
|---|---|
| フォームの回答数（日別） | 最重要。投稿ごとに回答がどれだけ増えたか |
| プロフィールのリンククリック数 | 投稿 → 回答の流れが途切れていないか |
| 職種別の回答数 | 狙う職種に届いているか |
| 保存数・返信数 | 共感されている投稿の型を見つける |
| 先行案内の登録数 | 先行販売の見込み |
- フォロワー数は補助的な数字。少なくても、回答と聞き取りが取れていれば進められる。

## 7. 安全・規約・倫理（必ず守る）
- **患者情報・院内の出来事を書かない。** 症例、画像、日時や場所が特定できる話題はNG。
- **勤務先が特定される投稿をしない。** 自院の制服・院内写真・設備の写り込みに注意。
- **勤務先の規程を確認する。** 副業・兼業、SNS利用、職務上知り得た情報の扱い。
- **調査の説明を正確に。** 回答の使い道（商品開発・販売の調査）、匿名であることを明記。
- **謝礼・抽選は条件を明記。** 景品表示法や各SNSの規約を確認。
- **広告・宣伝の表示。** 商品の宣伝は、宣伝であることが分かるようにする（ステルスマーケティング規制に注意）。
- **フォロワー購入・相互フォロー集めはしない。** 規約違反になり、アカウント停止のリスクがある。
- **DMの大量送信をしない。** 面識のない相手へのまとめ送信はスパム扱いになりやすい。
- **個人情報（メール等）は別管理。** 先行案内の登録メールは、案内のみに使う。

## 8. 運用体制・道具
- 運用は1人想定。投稿は週1回まとめて下書き（予約投稿機能を使う）。
- 画像づくり: Canva などのテンプレートで、色・フォント・ロゴを統一。
- 記録: 投稿日・文面・回答数の増減をスプレッドシートに記録し、効いた型を残す。
