# 医療職向け ニーズ調査ツール

SNS(Instagram・X)で医療職にアンケートを取り、**どの雑務に需要があり、いくらなら払うか**を集計して、
開発・販売するソフトの優先順位と価格を決めるための道具です。

| ファイル | 内容 |
|---|---|
| `questionnaire.md` | アンケート設計書(質問・選択肢・注意書き・SNS運用の注意) |
| `analysis.py` | 集計ロジック(需要スコア・Van Westendorp 価格感度・購入意向) |
| `survey_app.py` | 回答CSVを読み込んで集計を表示する画面 |
| `make_sample_data.py` | 動作確認用のダミー回答 `sample_responses.csv` を作る |

## 使い方
1. `questionnaire.md` の質問で Google フォームを作り、リンクを SNS に投稿する。
2. 回答を CSV でダウンロードする(フォームの「回答」→ スプレッドシート → CSV)。
3. `pip install -r requirements.txt` → `streamlit run survey_app.py` で CSV を読み込む。
   (まず「ダミーデータで試す」で画面を確認できます。ダミーは `python make_sample_data.py` で作成)

## 見方
- **需要スコア** = 平均負担度 × 平均解決意欲(最大25)。上位が「作る価値のある雑務」の候補。
- **価格感度**: 許容範囲(PMC〜PME)と最適価格(OPP)。月額の目安に使う。
- **購入意向**: 「ぜひ」「条件次第」の割合と、支払う人(個人/施設)。

## 注意
- 回答は SNS 利用者に偏ります。管理職など購入の決定権を持つ人への個別ヒアリングで補ってください。
- 回答の「買いたい」は実際の購入より多く出ます。試作品での先行予約・先行販売の申込みで検証してください。
- 患者・個人が特定できる情報は集めないでください。
