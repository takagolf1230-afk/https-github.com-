# SNS投稿文（Instagram / X）

`【フォームURL】` は、実際のGoogleフォームのURLに置き換えてください。
所要時間は軽量版（約1分）に合わせています。

3枚目: 「プロフィールのリンクから回答」＋「個人・患者情報は書かないでください」

### ストーリーズ
```

```

## 返信・DMでの声かけ（任意）
```
お世話になっております。医療現場の雑務を減らすソフトを開発しており、
現場の方にアンケートをお願いしています（1分・匿名）。
お時間のあるときにご協力いただけるとうれしいです。
【フォームURL】
```
※ 面識のない相手へ大量に送るとスパム扱いされます。投稿とハッシュタグ経由を基本にしてください。

## 投稿のコツ
- 投稿は平日の夜（21〜23時）か、昼休み（12〜13時）が見られやすい傾向です。
- 回答が止まったら、文面を変えて再投稿（案A→B→C）。同じ文面の連投は避ける。
- 「リンクはプロフィールに」とし、Instagram はプロフィールのリンク欄にフォームURLを入れておく。
- 回答のお礼と結果共有を後日投稿すると、次回の調査にも協力してもらいやすい。

## 注意（必ず守る）
- 勤務先や所属が特定される形での投稿・拡散依頼は避ける。
- 「医療従事者向け」を装って、医療機関の備品・患者情報に触れる内容は書かない。
- 謝礼や抽選を付ける場合は、条件（対象・当選人数・個人情報の扱い）を明記する。景品表示法や各プラットフォームの規約に注意。
- フォームの収集目的に「ソフトの開発・販売の調査」を含めてあること。説明文の「商品開発の調査」で足りるが、販売意図を隠さない文面にする。

## 全国の医療系に広げる場合のハッシュタグ・文面（追記）
対象を医療系全体にしたので、職種を並べて書くと届きやすくなります。投稿は、職種ごとに少し言い回しを変えて別投稿にするのがおすすめです。

**ハッシュタグ候補（職種別）**
- 看護: `#看護師` `#看護師あるある` `#新人看護師` `#看護学生`
- 技師: `#診療放射線技師` `#臨床検査技師` `#臨床工学技士`
- 薬剤・栄養: `#薬剤師` `#病院薬剤師` `#管理栄養士`
- リハビリ: `#理学療法士` `#作業療法士` `#言語聴覚士`
- 歯科: `#歯科衛生士` `#歯科医師`
- 医師・事務・福祉: `#研修医` `#医療事務` `#介護職` `#医療ソーシャルワーカー`
- 共通: `#医療従事者` `#医療職` `#医療現場`

【フォームURL】/?src=x

**流入元の付け方（URL末尾）**: `?src=x` / `?src=ig` / `?src=ig_story` / 職種別に出すなら `?src=x_nurse` `?src=x_pt` など（半角英数字・`_`・`-`、20文字まで）。
