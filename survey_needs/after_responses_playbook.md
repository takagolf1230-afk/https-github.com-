# 回答が集まった後の流れ（アンケート → 試作 → 先行販売）

目的: 「作るソフトを1つに絞り、買い切り価格を決め、**実際にお金を払う人がいるか**を確かめる」。
アンケートは入口にすぎず、最後は先行予約・先行販売で確かめます。

## 全体像
| 段階 | やること | 目安期間 | 終了の判断 |
|---|---|---|---|
| 1. 回収 | 回答を集め、CSVを取り出す | 1〜2週間 | 回答50件以上（職種別に見るなら各30件） |
| 2. 分析 | `survey_app.py` で集計する | 半日 | 候補の雑務を2〜3個に絞れた |
| 3. 深掘り | 回答者・知人に聞き取り（5〜10人） | 1週間 | 「何に困り、今どう対処しているか」が言える |
| 4. 試作 | 最小のソフト（画面見本や簡易版）を作る | 1〜3週間 | 見せて「欲しい」と言われる |
| 5. 先行予約 | 価格を示して予約・購入を募る | 2〜4週間 | 実際に申込み・支払いがある |
| 6. 判断 | 作り込む / 方向転換 / 中止 | — | 下の判断基準を参照 |

## 1. 回収
- 回答が止まったら、`sns_posts.md` の別案で再投稿する。同じ文面の連投は避ける。
- 回答数が少ない職種（10件未満）は、その職種の結論を出さない。
- 回答CSVは、**先行案内用のメールアドレスの列を削除してから**分析に使う。メールは別ファイルに分けて保管し、案内以外に使わない。

## 2. 分析（`survey_app.py`）
1. 回答CSVを読み込み、「列の割り当て」が正しく認識されているか確認する。
2. 見るポイント（軽量版）:
   - **需要の大きい雑務**: 選択数ランキング。上位3つが候補。
   - **立場別・職種別の選択率**: 若手と管理職で上位の雑務が違うか確認する（使う人と買う人のズレ）。職種で上位が違えば、狙う職種を絞る。
   - **価格**: 「この金額以上を許容(%)」を見る。たとえば〜5,000円以上を許容する人が3割なら、5,000円前後が現実的。
   - **誰が払うか**: 「施設・部署」が多いなら、個人向けではなく施設向け（決裁・請求書対応）の売り方が必要。
   - **自由記述**: 候補の雑務について、具体的な困りごとを拾う。
3. 結果を1枚にまとめる（上位の雑務、狙う職種、価格帯、払う人）。

### 候補の絞り込み基準（目安）
| 観点 | 良い兆候 | 悪い兆候 |
|---|---|---|
| 需要 | 選択率が高く、職種を問わず上位 | 特定の少人数だけが選ぶ |
| 価格 | 3,000円以上を許容する人が2割以上 | 「払わない」が過半数 |
| 競合 | 既存の安価な代替が少ない（調べる） | 無料の既存ツールで足りる |
| 作りやすさ | 1人で1〜2か月で作れる | 電子カルテ連携など、院内システムとの接続が必須 |
| 法規・リスク | 患者情報を扱わない | 医療情報を扱い、医療情報ガイドライン対応が必要 |

**患者情報を扱わない業務（勤務表、当番割り振り、在庫、研修管理など）を、最初の製品にするのが安全で早い**です。
今回作った勤務表アプリは、この条件を満たす見本になります。

## 3. 深掘り（聞き取り）
アンケートで分からない「なぜ」と「購入の決定権」を、5〜10人に15分ずつ聞く。
- 今、その雑務をどうやっている（Excel・紙・既存ソフト）か。
- 1回にどのくらい時間がかかるか。月に何回あるか。
- 解決できたら何が変わる（時間・ミス・残業）か。
- 誰が買う・誰の承認が要る・予算はいつ決まるか。
- いくらなら即決できるか。それ以上は誰の決裁か。
- 管理職・購入の決定権のある人を、最低2〜3人含める（SNS回答は若手に偏るため）。
- 管理職は、若手の回答者・知人・元職場などから**紹介**してもらうと会いやすい。聞き取りの依頼文は、目的（雑務の調査）・所要時間（15分）・匿名で扱うことを明記する。

## 4. 試作（最小のもの）
- 最初は完成品にしない。**1つの雑務を解決する最小の機能**だけ作る。
- 画面見本（スクリーンショットや動画）を先に見せ、反応を見る方法でも十分。
- Streamlit でローカル動作させる今回の構成は、試作から販売版までそのまま使える（院内オフライン対応は強み）。
- 患者情報を扱わない設計にし、データはローカル保存。これを説明資料に明記する。

## 5. 先行予約・先行販売（ここが本番）
- 説明ページ（機能・画面・価格・提供時期・返金条件）を1枚作る。
- 価格は、アンケートの許容価格の範囲内で1〜2案を提示（例: 先行価格 4,980円 / 通常 9,800円、いずれも買い切り）。
- 申込み方法: 先行予約フォーム、または既存の決済サービス（BOOTH、Stripe、Coconala 等）。
  **実際の入金・予約**を数える。「欲しい」という返事は数えない。
- 返金条件と、ライセンス（個人1台か施設内何台か）を決めておく。
- 先行案内に登録した人へ、まず案内する。

### 販売前に確認すること（法務・規約）
- 特定商取引法に基づく表記（事業者名・連絡先・返品条件）が必要になる場合が多い。
- 医療機器に該当する機能（診断・治療の補助など）を含めない。**勤務表・事務支援は対象外**になりやすいが、機能が増えたら確認する。
- 個人情報（先行案内のメール）の取り扱いを、プライバシーポリシーに書く。
- 勤務先の副業・兼業規程と、職務で得た情報・知見の扱いを確認する。
- 迷う点は、販売前に専門家（弁護士・行政書士）へ相談する。

## 6. 判断基準（目安）
| 結果 | 次の動き |
|---|---|
| 先行予約が10件以上、または明確な法人の引き合いがある | 作り込み・正式販売へ |
| 関心は高いが申込みが少ない | 価格・見せ方・買う人（個人/施設）を変えて再テスト |
| 関心が低い | 次点の雑務に切り替える（アンケートの2〜3位） |
| 3回続けて反応がない | 市場・訴求先を見直す（職種、売り方、課題の選び直し） |

数字はあくまで目安です。回答の偏りが大きい調査なので、数字より「実際にお金を払った人の特徴」を重視してください。

- 試作の仕様書（選んだ雑務に合わせて）
