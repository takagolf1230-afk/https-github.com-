# デスクトップに「ない」とき

ソフトは **あなたのPCには自動では入りません。**  
いま入っているのは GitHub の作業ブランチです。`main` には README しかありません。

## 今すぐデスクトップに置く（いちばん簡単）

1. 下のZIPをダウンロードする  
   https://github.com/takagolf1230-afk/https-github.com-/archive/refs/heads/cursor/coconala-listing-docs-33f2.zip

2. ZIPを右クリック → **すべて展開**  
   できれば展開先を **デスクトップ** にする

3. できたフォルダを開く（名前はだいたい）  
   `https-github.com--cursor-coconala-listing-docs-33f2`

4. その中にあるどれかをダブルクリック  
   - `create_desktop_shortcut.bat`（英語名・見つけやすい）  
   - または `デスクトップにショートカットを作る.bat`

5. デスクトップに **「構造くん」** ができるので、それをダブルクリック

## フォルダの中にある起動ファイル

| ファイル | 意味 |
|---|---|
| `create_desktop_shortcut.bat` | デスクトップにアイコンを作る |
| `start_kouzokun.bat` | ソフトを起動する |
| `デスクトップにショートカットを作る.bat` | 上と同じ（日本語名） |
| `構造くんを起動.bat` | 上と同じ（日本語名） |

## よくある勘違い

- 昔の `Analyze_keiba` フォルダには **入っていません**（別物です）
- GitHub の `main` を見ても **まだありません**（PRブランチ側にあります）
- Cloud Agent の中だけにあっても、Windowsのデスクトップには出ません

## それでも無いとき

展開したフォルダの中で、検索欄に `start_kouzokun` と入れてください。  
それも無ければ、別のブランチ/別ZIPを開いています。上のZIPリンクをもう一度使ってください。
