# 現行予想と新系統で何が変わるか

前提: **現行は動かさない。** 下表は「実戦で使うものがどう違うか」の対比。置き換えではなく並行。

---

## 一言でいうと

| | 現行 | 新系統 |
| --- | --- | --- |
| 狙い | **複勝圏に残る馬**を拾いやすい | **1着を取れる条件が揃った馬**を軸にする |
| レース | 広めに戦う想定（現行フローのまま） | **厳選**（読めない／薄いオッズはケン） |
| 公開評価 | **RPM-10 のまま** | 内部は的中・回収・見送りも見る |

---

## 項目別の違い

### 1. 馬の見方（いちばん大きい変化）

| | 現行 | 新系統 |
| --- | --- | --- |
| 主問 | 3着以内に残るか | **この競馬場・距離・枠・馬場で勝ちきれるか** |
| スコア | 複勝寄りの評価 | `win_score`（勝ちきり条件マッチ）＋別途 place/dark |
| ◎の意味 | 現行ロジックの本命 | 勝ちきり適合が最も高い馬 |
| △の意味 | 現行どおり | 「残る力」寄り（複勝発想を印のヒモ側に残す） |

同じ「強い馬」でも、現行で○▲だった馬が新系統では◎になりにくくなり得る（複勝は強いが勝ちきり条件が弱い場合）。

### 2. レースの選び方

| | 現行 | 新系統 |
| --- | --- | --- |
| 基本 | 現行の対象レースに沿う | 全レース採点して **Pass / ケン** |
| ケンする例 | 現行ルール次第 | 混戦（軸が立たない）、情報不足、**オッズが薄すぎる** |
| 残す例 | — | 軸が抜けている堅実、軸堅・下位荒れ（神戸新聞杯型） |

結果として、**買うレース数は現行より減りやすい**。その分、残したレースに厚く張る。

### 3. 印の付け方

| | 現行 | 新系統 |
| --- | --- | --- |
| 生成 | いまのシステム | 機械印（他予想家型の役割分担） |
| 軸 | 現行の◎ | 原則◎固定。自信Lowはレースごとケン |
| 相手 | 現行の相手集合 | ○▲△（☆は下位荒れのときだけ） |

### 4. 買い目・券種

| | 現行 | 新系統 |
| --- | --- | --- |
| 券種 | いまの決め方（複勝特化の運用を含む） | **レース型で切替**（T1〜T7） |
| 例 | ワイド中心など現行パターン | 堅実→ワイド/馬連少点、小回り中荒れ→三連複広め、条件付きだけ三連単 |
| 低配当 | 現行どおり | **床下はケン**（的中しても薄い点は買わない） |

「いつも同じ券種」から「レースの質で券種が変わる」のが見た目の変化。

### 5. データの使い方

| | 現行 | 新系統 |
| --- | --- | --- |
| ソース | 既存（JRA公式を含む現状） | **JRA公式 JV-Data に固定**（`--db`） |
| オッズ | 現行の使い方 | 馬評価の主特徴にはせず、**購入ゲート（床・EV）専用** |
| コース | 現行ファクター | 場×距離×枠×脚質の**勝ちきり条件表**を明示的に照合 |

### 6. 評価・X公開

| | 現行 | 新系統 |
| --- | --- | --- |
| ものさし | **RPM-10（変更なし）** | RPM-10は触らない |
| 追加 | — | 的中率・回収率・見送り率などを内部比較用に併記 |
| X | いまの出し方のまま | 当面は現行ベース。新系統は検証用 |

## 同じレースで起きうること（イメージ）

例: 軸候補は強いが「複勝向き」、別馬が同コース勝ち多数。

| | 現行（複勝特化） | 新系統（勝ちきり） |
| --- | --- | --- |
| ◎ | 安定して残る方 | 同条件で勝ちきれる方 |
| 券種 | 現行テンプレ | 軸の自信と荒れ度で T を選択 |
| ワイドが極端に薄い | 買うこともあり得る | **ケン or 三連単など床上の券種だけ** |

神戸新聞杯型（軸1.4倍・3着大穴）:

- 現行: 複勝・ワイド発想だと軸は当たりやすいが払戻は薄い点が多い  
- 新系統: 軸は勝ちきりで採用しつつ、薄い本線はケン。穴に条件根拠があれば三連単ゲートだけ開く  

---

## 変わらないこと

- 現行システムのコード・印・買い目ロジック・RPM-10・X運用  
- データは同じ公式DBを読んでよい（新系統は読み取り専用の別コード）  
- 新系統が勝つまで、実戦の主軸は現行  

---

## 使う人から見た変化（並行期間）

```text
今まで: 現行だけで予想 → RPM-10で評価 → X
これから:
  現行: 今まで通り（主軸）
  新系統: 別出力で「このレースはケン／この印／この券種」
  あとで両方の成績を並べて、置き換えるか判断
```
