## 実績0でも買う理由を作る

1. 公開統計PDF（e-Statや自治体資料）で Before/After 画像を3枚。架空のきれいな表だけは弱い。
2. 1枚目: PDF → 列揃え → Excel/CSV。2枚目: 結合セルが外れて数値が計算できる例。3枚目: 向いている資料の箇条書き。
3. 「初回プレビュー可・残3枠」をキャッチに固定。
4. 見積もり相談は12時間以内（できれば3時間）。
5. 最初の3件は小さくても引き、評価文で「列が揃った／要確認があって安心」を取りにいく。
