# 収益化の進め方（ロードマップ）

対象: 自作の業務アプリ（勤務表・機器管理・線量管理・健康診断問診票）を、**個人事業主として小さく販売**する。
前提: ソフトだけを配布し、**個人データは開発者が持たない**（データは施設が入力した分だけ、利用者のPC内に保存）。
作成日: 2026-10-22 ／ 税務・法務・契約の細部は、税務署・税理士・専門家に確認すること（これは一般的な整理です）。

---

## 0. 方針（結論）
- [ ] **会社は作らない。** まず個人事業主（開業届）で販売する。
- [ ] **最初は自分で直販する。** 業者（代理店・ソフト会社）は、実績ができてから相談する。
- [ ] **リスクの低いものから出す。** 勤務表 → 機器管理 → 線量管理 → 問診票。
- [ ] **小さく試す。** 先行予約で、実際に買う人がいるかを確かめてから作り込む。

| 順 | アプリ | 扱う情報 | リスク | 出す条件 |
|---|---|---|---|---|
| ① | 勤務表 | 職員名・勤務予定 | 低 | すぐ |
| ② | 機器管理 | 機器の点検・保守・期限 | 低 | すぐ |
| ③ | 線量管理 | 職員の被ばく線量（患者線量は別） | 中 | ログ・バックアップ・通信なしを整えてから。まず職員の被ばく管理に限定 |
| ④ | 健康診断問診票 | 受診者の健康情報 | 高 | **判定・診断を示す機能がないこと**を確認してから |

---

## 1. 権利・規程の確認（最優先）
- [ ] 勤務先の就業規則（副業・兼業、著作物の帰属、職務上知り得た情報）を確認する。
- [ ] 業務時間・職場の備品・職場のデータで作っていないか、整理する。
- [ ] 公務員（公立病院の職員など）は、兼業の許可が必要。
- [ ] 迷う場合は、上長・総務に「個人で作った汎用ソフトを公開したい」と相談する。
- [ ] 業者に持ち込む場合に備え、**権利の所在を書面で整理**する。

## 2. 配布物の整備（商品として整える）
- [ ] **院内情報の除去**: 施設名・氏名・メール・パス・ID・パスワードを検索して、残っていないか確認する。
- [ ] 設定ファイル・ログ・DBの初期データ・サンプルに、実在の名前がないか確認する。
- [ ] **Gitの履歴に院内情報が残っていないか**確認する（残っていれば、新しいリポジトリで配布する）。
- [ ] ダミーデータ版を作る（説明・画面・動画用）。
- [ ] 外部へ通信しないことを確認し、説明書に明記する。
- [ ] 必要な安全機能を備える: ログイン／アクセス権限／操作ログ／バックアップ／暗号化（範囲は製品ごとに決める）。
- [ ] **第三者のPCで、説明書だけで導入できるか**試す。
- [ ] 医療機器に当たらないかを確認する（判定・診断を示す機能がないか）。迷えば専門家・PMDAの相談窓口へ。

## 3. 販売の土台（書類・規約）
- [ ] 利用規約（免責: データ消失、診断・判断に使わないこと、バックアップは利用者責任）
- [ ] サポート範囲（問い合わせ方法、対応時間、対応しないこと）
- [ ] **サポート時にデータを見ない運用**を決める（データを送ってもらわない、など）
- [ ] 返金条件、ライセンス範囲（1施設・何台まで、など）
- [ ] 特定商取引法に基づく表記（氏名・住所の扱いは、公開方法を確認）
- [ ] プライバシーポリシー（先行案内のメールアドレスの取り扱い）
- [ ] 施設向けの**セキュリティ説明資料**（通信しない／データは施設内のみ／保存場所／ログ／バックアップ）
- [ ] 請求書・領収書の発行方法（施設は請求書払いを求めることが多い）

## 4. ホームページを「売る場」にする
自分のホームページに、次の要素を入れる。
- [ ] 製品ページ（できること、画面、30秒〜1分のデモ動画）
- [ ] 先行予約の入口、資料請求、メール登録フォーム
- [ ] 価格（先行価格。2〜3通りを試す）
- [ ] FAQ（動作環境、データの場所、サポート、返金）
- [ ] 特定商取引法の表記、プライバシーポリシー、問い合わせ
- [ ] 実在する利用者の声（**許可を得たもののみ**。ない間は載せない）

※ 文面の雛形: `survey_needs/presale_page.md`

## 5. 発信を始める（お金をかけずに）
- [ ] **X**: 開発の裏話、使い方、現場あるあるを、診療放射線技師向けに発信する。
- [ ] **Instagram**: 画面・動画で見せる。
- [ ] **note / Zenn**: 検索される記事（例: 「放射線科の勤務表をExcelで自動作成」）。無料テンプレートで集客し、ソフトへ誘導する。
- [ ] **勉強会・技師会・学会**: 登壇・LT・展示で、技師長・管理職に知ってもらう。
- [ ] **無料版・体験版**を出し、有料版へつなげる。
- [ ] 有料広告は、反応が確かめられてから。

※ 資料: `survey_needs/account_design.md`、`survey_needs/sns_posts.md`

## 6. 需要と価格を確かめる
- [ ] SNSアンケートで、需要の大きい雑務を調べる（`survey_web/`）。
- [ ] 先行案内を希望した人へ、先行予約を案内する。
- [ ] 管理職（技師長・主任）5〜10人に、15分の聞き取りを行う（`survey_needs/interview_sheet.md`）。
- [ ] **価格は2〜3通りで反応を見る**（実際の申込み・入金を数える。「欲しい」は数えない）。

| 結果 | 次の動き |
|---|---|
| 先行予約が複数ある／施設から引き合いがある | 開業届を出し、正式販売へ |
| 関心は高いが申込みが少ない | 価格・見せ方・買う人（個人か施設か）を変えて再テスト |
| 関心が低い | 別のアプリ（②→③）に切り替える |

## 7. 開業・販売開始
- [ ] 個人事業主として**開業届**を税務署に提出する。
- [ ] 副業の場合は、勤務先への届出・住民税の扱い（普通徴収など）を確認する。
- [ ] 所得が年20万円を超える見込みなら、確定申告の準備をする（目安。詳細は税務署・税理士へ）。
- [ ] 決済手段を決める（BOOTH／自サイト＋決済サービス／請求書払い）。
- [ ] 売上・経費を、最初から記録しておく。

## 8. 業者に相談するのは「実績ができてから」
| 方法 | 良い点 | 注意点 |
|---|---|---|
| 自分で直販（最初） | 利益が残る。顧客の声が直接届く | 販路とサポートを自分でやる |
| 販売代理店・医療系商社 | 病院への販路・信用 | マージン。価格と顧客の主導権を失いやすい |
| 既存ソフト会社へライセンス・譲渡 | 一括収入・ロイヤリティ | 権利の整理が必須。買い叩かれやすい |

- [ ] 持ち込む前に、**権利の整理**と**秘密保持契約（NDA）**を済ませる。
- [ ] 実績（購入者数・継続率・感想）を資料にまとめてから交渉する。

## 9. 会社設立を考えるタイミング
次のいずれかが出てから検討する（今は不要）。
- 取引先の病院・企業から**法人格や法人契約を求められる**。
- 売上・利益が安定して大きくなった（税負担を比較して判断。税理士に相談）。
- 共同開発者・従業員を入れる。
- 責任の範囲を分けたい（個人と事業を分けたい）。

---

## 注意・リスク
- 収益の規模は予測できない。**売れる保証はない**。小さく試して確かめる。
- 同種の既存製品・無料ツール・院内の既存システムで足りている施設も多い。**競合を先に調べる**。
- 売ると、問い合わせ対応・不具合の責任が生じる。**続けられる範囲**を決める。
- 実績のない数字・実在しない利用者の声を書かない。医療機器に当たる表現を避ける。
- データを扱う機能（ログイン・氏名入力など）を足すほど、責任が重くなる。最初は「データは利用者のPC内」の形を守る。
