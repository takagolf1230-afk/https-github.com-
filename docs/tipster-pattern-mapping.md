# 他予想家の型を当てはめる運用設計

目的: 新聞・指数・データ予想家が使っている **印の決め方 / 軸の取り方 / 買い方** を、過去走DBによる馬評価と、的中寄り（レース選別＋券種可変）に接続する。

前提:

- 馬の評価は過去走DBでできる（L1）
- 印・軸・買い方は「予想家の型」をルール化する（L2〜L3）
- 当面は **印ルールを1本に固定**し、券種マトリクスとレース選別の効果を測る

---

## 1. 予想家が共通してやっていること

成功している側の作業順は、ほぼ次で共通する。

```text
1. 各馬を評価する（指数・実績・展開）
2. 印を付ける（◎○▲△☆）…「強さの言語化」
3. レースの型を読む（堅い / 混戦 / 軸堅・下位荒れ）
4. 軸を決める（ほぼ◎、例外で○）
5. 相手の範囲を決める（印の集合で切る）
6. 券種と買い型を選ぶ（流し / フォーメーション / 見送り）
```

当てはめ方針: **1はあなたのDB、2〜6は他予想家の型を機械ルール化**する。

---

## 2. 印の決め方（予想家標準 → DBルール）

### 2.1 印の意味（新聞・プロ共通）

| 印 | 呼び名 | 予想家の意味 | DBへの写像 |
| --- | --- | --- | --- |
| ◎ | 本命 | 最も勝つ確率が高い。軸の基本 | `win_score` 1位、かつ2位との差が十分 |
| ○ | 対抗 | ◎を負かすならこの馬。2番手実力 | `win_score` 2位、または `place_score` 上位かつ勝ち負け候補 |
| ▲ | 単穴 | 3番手。ハマれば勝ち負け。配当妙味 | `win_score` 3位、または展開が向けば浮上する馬 |
| △ | 連下 | 1着は厳しいが2・3着ならある | `place_score` 上位だが `win_score` は中位 |
| ☆ | 大穴 | 人気薄の一発。根拠があるときだけ | 人気低 ×（適性/展開/先行残り）根拠あり |
| ×/無印 | 切り | 相手に入れない | 上記以外 |

重要: 予想家の印は「人気順」ではない。**役割**である。  
◎=軸候補、○=対抗、▲=勝ち負け穴、△=ヒモ、☆=根拠付き大穴。

### 2.2 DBから印を付ける手順（推奨ルール）

各出走馬に過去走DBから出すスコア（例）:

- `win_score`: 勝ち切れそうさ（スピード指数・同条件成績・騎手等）
- `place_score`: 3着以内に残るさ
- `pace_role`: 逃/先行/差し/追込
- `cond_fit`: 距離・芝ダ・コース・馬場適性
- `gap_to_top`: 1位との差

印付けアルゴリズム（的中寄り・予想家型）:

```text
1. win_score 降順で候補を並べる
2. ◎ = win_score 1位
   - ただし gap_to_top(2位) が小さい（混戦）なら「◎の自信度=Low」を別フラグで持つ
3. ○ = win_score 2位
4. ▲ = win_score 3位、または
        place_score 上位かつ pace/cond で「ハマれば」条件を満たす1頭
5. △ = place_score 上位のうち、◎○▲以外から最大2〜3頭
6. ☆ = 人気が低いが dark_score（適性・展開根拠）が高い最大1頭
7. それ以外は ×（相手禁止）
```

頭数の目安（予想家の一般的な付け方）:

- ◎○▲: 各1頭（必須に近い）
- △: 2〜3頭
- ☆: 0〜1頭（根拠なしなら付けない）

### 2.3 コンピ指数勢の型を借りる部分

日刊コンピ系でよく使われる考え方:

- **上位と下位の指数差**で軸の信頼度を見る
- **上位3頭の指数合計**で順当〜波乱を見る
- 軸は基本 **指数1〜3位から**
- 相手は **上位N位まで** で線を引く（例: 8位以内）

DBへの移植:

```text
axis_solid =
  win_score(1位) - win_score(2位) が大きい
  かつ win_score(1位) 自体が高い

field_chaos =
  win_score 上位3頭の差が小さい
  または place_score 上位と win_score 上位が食い違う
  または 人気順位と DB順位が大きくズレる
```

これは前回決めた `axis_solid` / `field_chaos` そのもの。

## 3. 予想軸のやり方（当てはめ）

### 3.1 軸の基本（ほぼ全予想家共通）

| 状況 | 軸の取り方 |
| --- | --- |
| ◎が抜けている | **軸=◎ 固定**（1頭軸） |
| ◎○が僅差 | 軸2頭（◎○）または ○も軸候補 |
| 混戦で◎自信なし | **そのレースは買わない**（的中寄り） |
| 穴党タイプ | ◎以外を軸にする人もいるが、的中寄りでは採用しない |

本方針: **軸は◎のみ。◎自信度が低いレースは Skip。**

### 3.2 軸の自信度（新聞の「◉」に相当）

一部記者は自信本命に ◉ を使う。機械化すると:

```text
axis_confidence =
  High: gap大 + win_score突出 + 同条件実績あり
  Mid:  1位だが差が小さい
  Low:  1位でも混戦 / 情報不足
```

- High → 本線勝負、点数少なめ・配分厚め
- Mid → ワイド中心、軽め
- Low → Skip

神戸新聞杯（ロブチェン）は典型の **axis_confidence=High**。

### 3.3 相手（ヒモ）の決め方

予想家の王道:

- 相手の母集団 = ○▲△（必要なら☆）
- ×は入れない
- 「一応人気だから」で広げない

あなたの既存実験固定と一致:

- 相手 = ◯▲△（×除外）
- ☆は **軸堅・下位荒れ** のときだけ三連系の3着候補に追加可

## 4. 買い方の型（印 → 券種テンプレ）

予想家・JRA解説・フォーメーション派の共通型を、レース構造に割り当てる。

### 4.1 テンプレート一覧

| ID | レース型 | 軸 | 買い型 | 券種候補 | 点数感 |
| --- | --- | --- | --- | --- | --- |
| T1 | 堅実（軸High・下位Low） | ◎ | ◎→○▲ 流し | 馬連/ワイド中心 | 少 |
| T2 | 堅実＋並び自信 | ◎ | 三連単F: 1着◎ / 2着○▲ / 3着○▲△ | 三連単 | 6〜12 |
| T3 | 軸堅・下位荒れ | ◎ | 本線 ◎→○▲△ ワイド/馬連。穴根拠あれば 3着に☆1頭 | ワイド+条件付き三連単 | 中 |
| T4 | 中荒れ・直線長 | ◎ | ◎軸のワイド＋三連複少点 | ワイド/三連複 | 中 |
| T5 | 中荒れ・小回り | ◎ | 相手広めのワイド/三連複 | ワイド/三連複 | やや多 |
| T6 | 混戦（軸Low） | - | **見送り（ケン）** | - | 0 |
| T7 | オッズ過薄 | - | **見送り（ケン）** | - | 0 |

これが「券種は絞らずレースの質で変える」の実体。

### 4.1.1 オッズが低すぎるときはケン（見送り）

的中しても払戻が薄い買い目は買わない。軸が強くても例外にしない。

判定タイミング: テンプレ T1〜T5 を選んだ**あと**、購入直前に実オッズ（または発売中オッズ）でゲートする。

```text
候補買い目ごとに:
  odds < odds_floor(券種)  → その点は捨てる
残点が0、または本線券種の代表オッズが全部床下
  → そのレースはケン（T7 / 見送り）
```

初期フロア（バックテストで調整する仮値）:

| 券種 | odds_floor（100円あたり倍率の目安） | 例 |
| --- | --- | --- |
| ワイド | 2.5倍（250円） | 神戸新聞杯ワイド1-4=280円はギリギリ〜床下寄り |
| 馬連 | 4.0倍 | 590円なら通過 |
| 馬単 | 5.0倍 | |
| 三連複 | 8.0倍 | |
| 三連単 | 20.0倍 | 33,530円は通過 |

運用ルール:

- **本線が床下で、昇格先だけ床上** → 昇格してよい（例: ワイドが薄すぎるので三連単T3へ）。ただし三連単ゲート（穴根拠・点数上限）は別途満たすこと
- **全候補が床下** → ケン（買わない）。的中率のためだけに极端な低配当を積まない
- 単勝1.1〜1.5倍台の軸でも、ヒモ側に妙味があればワイド/三連は買い得る。床判定は **買う券種のオッズ** で見る
- フロア数値は設定ファイル化し、的中率と平均配当のバランスで週次調整

やらないこと:

- 「◎が強いから低配当でも厚く買う」
- 床下の点を保険で残す（点数だけ増えて払戻が薄い）

### 4.2 印から買い目への変換（予想家がよくやる具体例）

```text
馬連・ワイド（的中本線）:
  ◎ → ○▲△

三連複（中荒れ・小回り）:
  軸◎、相手○▲△（必要なら☆）

三連単フォーメーション（厳格）:
  1着: ◎
  2着: ○▲
  3着: ○▲△（＋☆は根拠があるときだけ）
```

やらないこと（的中寄り）:

- 無印まで入れた総流し
- 軸なしBOXを常用
- 混戦で三連単BOX

### 4.3 神戸新聞杯型への当てはめ例

結果: `1-4-8`（◎級–○級–☆級）

予想家型で再現するなら:

```text
◎ = ロブチェン（axis High）
○▲△ = 実力上位の相手
☆ = シートゥサミット（逃げ残り・展開根拠がある場合のみ）
T3: ワイド本線 + 三連単Fで 3着に☆を残す
```

☆を付けられない（根拠なし）なら三連単は買わず、ワイド/馬連で止める。  
そのワイド/馬連も `odds_floor` を下回るなら **ケン**（このレースは買わないか、床を超える点だけ残す）。

## 5. あなたのDB運用への統合（決定案）

```text
過去走DB
  → L1: win_score / place_score / pace_role / cond_fit / dark_score
  → L2: 印付け（§2.2）+ axis_confidence + field_chaos
  → L3: テンプレ T1〜T6 で券種・買い型
  → L4: 点数上限・配分（レース同額÷点数、Highは厚く）
  → L5: オッズ床ゲート（床下は捨てる / 残点0ならケン）
```

検証の順番（混ぜない）:

1. **印ルール固定**（§2.2）で過去レースに機械印を振る
2. **T1〜T6** だけで的中率を測る（実印や人間印と並列比較してもよい）
3. 良ければ券種マトリクスの閾値だけ調整
4. その後に Ranker で印ルール自体を学習で置き換え

Logic Horse 既存方針との関係:

| 項目 | 方針 |
| --- | --- |
| 印 | 当面は §2.2 の機械ルール（または現行印）を固定して券種検証 |
| 相手 | ◯▲△（☆はT3限定） |
| 券種 | T1〜T7（レース型で切替。オッズ過薄はT7ケン） |
| オッズ床 | 券種別 `odds_floor`。床下は買わない |
| 合成オッズ | 後回し |
| DB | **JRA公式 JV-Data**（`--db` で `jv_data.db` 実集計） |

## 6. 他予想家タイプ別の取り込み可否

| タイプ | 取り込むこと | 取り込まないこと |
| --- | --- | --- |
| 新聞印（スポニチ等） | 印の役割定義、◎軸流し | 記者ごとの癖をそのまま真似 |
| コンピ系 | 指数差で堅実判定、相手の順位カット | コンピ数値そのものへの依存（自前DBで代替） |
| フォーメーション派 | 着順別に頭数を変える買い方 | 毎レース三連単 |
| 穴党・回収派 | ☆の根拠付き1頭 | 軸なし穴軸の常用（的中方針と衝突） |
| AI/Ranker勢 | レース内相対評価、時系列リーク禁止 | 確定オッズ主特徴 |

---

## 7. 次に決める実装単位

最小の次ステップ（コード化単位）:

1. DB → `win_score` / `place_score` / `dark_score` の定義を1ページに固定
2. §2.2 で機械印を出力
3. `axis_confidence` × `field_chaos` → T1〜T6 を選択
4. 買い目リストと点数を吐く
5. 過去N年で的中率・見送り率を集計

これで「他予想家の印・軸・買い方」を、あなたのDB評価に載せた再現可能な型になる。
