# 受注後オペレーション（PDF表 → 構造化Excel）

最終更新: 2026-09-22  
対象サービス: [`coconala_pdf_excel_listing.md`](./coconala_pdf_excel_listing.md)

目標時間単価: 手数料前 **4,000円以上**。  
3,000円案件で **2時間を超えそうなら、受ける前にページ追加 or スキーマ追加を取る**。

---

## 初回だけ（半日）

- 抽出テンプレ: `pdfplumber` / `camelot` / `pypdf`
- 整理関数: pandas で型変換・全角半角・日付パース
- 納品ブックひな形: シート `data` / `review` / `log`
- 機密ファイル用の一時フォルダと、納品後削除チェックリスト

---

## フロー

### ① ヒアリング（15分）

チェックリスト:

1. PDFは文字を選択できるか（できない＝スキャン）
2. 欲しい表は何ページのどれか
3. 欲しい列名
4. 1行が何を表すか（1請求、1商品、1人 など）
5. 希望納期

基本範囲を超えるなら、オプション提示してから作業開始。

### ② データ受け取り

- 原則ココナラのトークルームのみ
- ファイル名を `YYYYMMDD_案件_元ファイル` に統一

### ③ 内容確認（15〜30分）

- ページ数、表の数、結合セル、ページまたぎを目視
- 1表プレビューを先に返す（列案つき）
- ここで合意した列が「完成定義」

### ④ AI / OCR 抽出

- テキストPDF: ライブラリ優先
- 失敗したページだけ OCR
- AIは見出し推定・列名統一案に限定
- **数値の創作は禁止**

### ⑤ Python 整理

- ページまたぎ結合
- 列順固定
- 型変換。失敗値は元文字列を残して `review` へ
- 重複キーがあればフラグ列

### ⑥ 目視チェック（必須・20〜40分）

- 先頭10行、末尾10行
- 金額列の合計と元PDF 1ページ分を突合
- 空欄率が高い列がないか
- 文字化け・列ズレは全件スキャン

### ⑦ 納品

- `xlsx` + `csv` + 短い作業メモ
- 「要確認シートの見方」を5行で書く
- 元データの削除予定日を伝える

### ⑧ 修正

- 無料1回は「列定義の変更」まで（列名・列順・明らかな抽出ミス）
- 新しい表の追加はオプション見積

---

## 時間目安（慣れた後）

| 案件タイプ | 目安 |
|---|---|
| 素直なテキスト表 5ページ | 40〜60分 |
| ページまたぎ・列名ゆれ | 70〜100分 |
| スキャン込み | 2〜3時間 |

---

## 納品チェックリスト（毎回）

- [ ] `data` シートが1行1データになっている
- [ ] ヘッダーが1行目、結合セルがない
- [ ] 日付・数値が型として扱える（文字列のまま残していない）
- [ ] `review` に取れなかった箇所がある（空欄で誤魔化していない）
- [ ] `log` に対象ページと列マッピングが書いてある
- [ ] CSV（UTF-8）を同梱した
- [ ] 修正回数と対象範囲をトークに明記した
- [ ] 作業用コピーの削除予定を伝えた
