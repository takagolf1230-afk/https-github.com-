# 成績が良い予想家の「真似すべき型」（模倣プレイブック）

目的: 個人名の丸暗記ではなく、**公開されて再現できる勝ちパターン**だけを抜き、あなたのDB＋的中/回収方針に移植する。

注意:

- 「今週当たった予想家」は真似しない（サンプル不足）
- 有料予想の買い目そのものより、**手順・ルール・見送り基準**を真似する
- 自前DBで同じルールをバックテストできない手法は採用しない

---

## 1. まず真似する本命セット（これだけやればいい）

成績が安定している側に共通し、あなたの方針とも衝突しない3型を **同時採用**する。

| 優先 | 真似元の型 | 真似する中身 | やらないこと |
| --- | --- | --- | --- |
| 1 | **レース波乱度分類**（コンピ・テクニカル6系） | 上位力関係の和/差で堅い〜波乱を分け、型ごとに軸と相手範囲を変える | 波乱型を毎回買う |
| 2 | **印→軸流し/フォーメーション**（新聞・プロ標準） | ◎軸、相手=○▲△、着順別に頭数を変える | 無印BOX、混戦三連単 |
| 3 | **ファクター加減点＋サンプル制約**（Team.D系） | 回収が出る条件だけ加点。件数少ない条件は無視。上限下限を付ける | 感覚だけの印 |

この3つをあなたの語彙に落とすと:

```text
DBスコア
  → 上位差・上位和で race_pattern（堅〜波乱）
  → 印 ◎○▲△☆
  → パターン別テンプレ（T1〜T7）
  → odds_floor / EV でケン
```

---

## 2. 型A: レースを先に分類する（テクニカル6系の真似）

### 何が強いか

田中洋平氏のテクニカル6系は、馬単位の「絶対評価」より先に  
**「このレースは堅いか波乱か」** を指数上位の関係だけで決め、買い方を切り替える。

公開されている骨格:

1. 能力指数の1〜3位を足す（または差を見る）
2. 合計が大きい → 堅い、小さい → 波乱
3. パターンごとに **軸ゾーンと相手ゾーン** を変える
4. 堅い型と波乱型で券種・点数を変える（同じ買い方をしない）

### あなたのDBへの移植（推奨ルール）

コンピが無くても、自前 `win_score` で同じことができる。

```text
s1, s2, s3 = win_score 上位3頭（正規化して0-100相当でも可）
top_sum = s1 + s2 + s3
top_gap = s1 - s2

pattern:
  Solid   : top_gap 大 かつ s1 高い          → T1/T2（堅実）
  AxisEdge: top_gap 大 かつ 下位混戦         → T3（軸堅・下位荒れ）※神戸新聞杯型
  Mid     : 中間                             → T4/T5
  Chaos   : top_gap 小 かつ top_sum 低い     → T6 ケン（的中・回収とも不利）
```

真似ポイント（ここが成績良い人の核）:

- **全レース同じ買い方をしない**
- 波乱と分かったら「当てに行く」より、的中寄りなら **ケン**
- 回収寄りでも、波乱は点数爆発しやすいので別ルール

## 3. 型B: 印と買い目の役割分担（新聞・プロ標準の真似）

### 何が強いか

長期で残る予想家は、印を「人気順シール」ではなく **買い目の部品** として使う。

| 印 | 役割 | 買い目での使い方 |
| --- | --- | --- |
| ◎ | 軸 | 1着or連対の固定点 |
| ○ | 対抗 | 2着候補の中心 |
| ▲ | 単穴 | 勝ち負け・ヒモの核 |
| △ | 連下 | 3着・ワイド相手 |
| ☆ | 根拠付き穴 | 下位荒れの3着候補だけ |

定番の買い目変換（そのまま採用）:

```text
ワイド/馬連: ◎ → ○▲△
三連複: 軸◎、相手○▲△
三連単F: 1着◎ / 2着○▲ / 3着○▲△(☆)
```

真似ポイント:

- 相手の母集団を印で切る（×を入れない）
- 自信度で流し／フォーメーション／ケンを切替
- 「当たった買い目」ではなく **切った馬** を真似する

---

## 4. 型C: ファクターで加点する（Team.D / データ予想の真似）

### 何が強いか

感覚印ではなく、過去回収が出る条件だけを点数化する。

公開されている評価作法の要約:

1. 仮説 → データ検証（先に物語を作らない）
2. 基準回収（例: 複勝80%）からの差分で加減点
3. **1ファクターに上限・下限**（効きすぎ防止）
4. **件数不足の条件は採用しない**（コース細分でNが減ったら重みを落とす）
5. 条件の切り方をファクターごとに変える（距離別が妥当なら距離別）

### あなたのDBへの移植

`win_score` を「単一の総合点」にするとき:

```text
base = スピード指数系（同条件相対化）
+ capped(騎手複勝バイアス)
+ capped(枠×コースバイアス)
+ capped(距離延長/短縮適性)
+ capped(脚質×想定ペース)
※各補正は ±数点で頭打ち
※直近1年を重く、古い年は軽く（または直近優先）
```

真似ポイント:

- 「効いた気がする」ファクターを無限に足さない
- 回収が説明できないデータは使わない
- 大穴だけが作る見かけ回収は捨てる（複勝オッズ上限で切る、など）

## 5. 型D: 予測と購入を分ける（AI/研究勢の真似）

AlphaImpact・回収率系AI・慶應のオッズ歪み研究に共通:

| 段階 | やること | 使うデータ |
| --- | --- | --- |
| 予測 | レース内順位・勝率 | 過去走のみ（オッズは主特徴にしない） |
| 購入 | 期待値・床で切る | 実オッズ |
| 検証 | 的中率・回収率・標準偏差 | 払戻 |

真似ポイント:

- 的中モデルを回収モデルと混ぜない
- 人気を当てる作業にしない
- 低オッズはケン（あなたのT7）

## 6. 「真似しない」リスト（成績が良く見えて危険）

| 見かけ | なぜ真似しないか |
| --- | --- |
| 今週の的中スクショ勢 | Nが小さい。再現手順がない |
| 全レース三連単BOX | 的中は出ても回収が壊れやすい |
| ◎＝1番人気固定 | DB評価の意味が消える |
| 確定オッズ込み学習の公開回収 | 実戦で再現できないことが多い |
| 穴だけ拾う「回収自慢」 | 分散が大きく、的中寄りと衝突 |

真似してよい人の条件:

1. 手順が文章化されている  
2. 見送り基準がある  
3. レース型で買い方を変えている  
4. 長期（目安50レース以上、理想は年単位）で語っている

## 7. あなたの週次オペに落とした「真似ルーチン」

成績良い人の手順を、そのまま週の作業にする。

```text
金〜土朝
  1. DBで全馬 win/place/dark スコア
  2. top_sum / top_gap で race_pattern
  3. Chaos → ケン
  4. それ以外に印付け（型B）
土日
  5. パターン別テンプレで買い目生成（型A×B）
  6. odds_floor / EV で削る（型D）
  7. 残点だけ購入（点数上限あり）
月曜
  8. 的中・回収・見送り率を集計
  9. ファクター加減だけ微調整（型C）。印ルールは週に一度まで
```

神戸新聞杯型の真似方:

- pattern = AxisEdge（軸抜け＋下位混沌）
- ◎は市場と同じでよい（軸の真似）
- 差は **☆をデータ根拠で1頭残すか**（ここがデータ予想の腕）
- ワイドが床下ならケンか三連単昇格のみ

---

## 8. 模倣の実装優先順

1. `top_gap` / `top_sum` → Solid / AxisEdge / Mid / Chaos（型A）  
2. 印付けと T1〜T7（型B＋既存テンプレ）  
3. odds_floor + EV（型D）  
4. ファクター加減点の整備（型C）  

「誰の買い目を買うか」ではなく、**誰の手順をコードにするか** で真似する。
