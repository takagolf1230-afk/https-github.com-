# SNS向け アンケートシステム

Instagram / X から、全国の医療職がスマホで1分で答えられる回答フォームと、パソコンで見る管理画面・CSV出力です。
集めたデータは**自分のパソコンの `survey.db`** に保存され、CSVを `survey_needs/survey_app.py`（分析アプリ）でそのまま分析できます。

- 回答画面: 1ページ・選ぶだけ・必須5問（職種／立場／負担が大きい雑務を3つまで／買い切りで払える金額／費用負担者）＋任意2問（困りごと／先行案内メール）
- 管理画面 `/admin`: 回答数、雑務ランキング、職種別、日別、流入元別、回答の削除、CSVダウンロード
- 質問の変更: `questions.py` を編集（画面・検証・CSV列が連動）
- 依存: Flask・waitress のみ。画面にCDNや外部通信はありません

## 1. パソコンで動かす
`run.bat` をダブルクリック → 管理画面のパスワードを入力 → `http://localhost:8000/` で回答画面、`/admin` で管理画面（ユーザー名は何でもよい）。

手動の場合（Mac/Linux など）:
```
pip install -r requirements.txt
ADMIN_PASSWORD=好きなパスワード waitress-serve --listen=127.0.0.1:8000 app:app
```

## 2. SNSの回答者に公開する（スマホから開けるURLが必要）
パソコンの `localhost` は他人から開けません。次のどちらかで公開します。

### A. トンネルでパソコンのサーバーを一時公開（データは手元に残る・調査期間だけ）
Cloudflare Tunnel（無料）などで、`localhost:8000` を `https://…` のURLに中継します。
```
cloudflared tunnel --url http://localhost:8000
```
表示された `https://xxxx.trycloudflare.com` を、SNS投稿のフォームURLにします。
- 回答中は、パソコンの電源を入れ、`run.bat` とトンネルを起動したままにする必要があります。
- 一時URLは起動のたびに変わります。固定URLにするには、Cloudflareアカウントとドメインでの設定が必要です。
- トンネル越しで運用するときは、環境変数 `TRUST_PROXY=1` を設定してください（回数制限の判定に使います）。
- 院内ネットワーク上のパソコンでは行わないでください。個人の自宅PCなど、許可のある環境で行います。

### B. クラウドに置く（PCを付けっぱなしにしたくない場合）
Render・Fly.io・VPS などに、このフォルダを配置して `waitress-serve --listen=0.0.0.0:$PORT app:app` で起動します。
- 環境変数 `ADMIN_PASSWORD`、`TRUST_PROXY=1` を設定する。
- **無料枠はディスクが消えるものがあります。** `survey.db` を保存する永続ディスク（または定期的なCSVダウンロード）が必要です。
- 料金・無料枠の条件は各サービスの最新の案内を確認してください。
- 回答はクラウド側のDBに溜まるので、こまめに管理画面からCSVをダウンロードして、パソコンで管理します。

## 3. 流入元を分ける
SNSごとにURLの末尾に `?src=` を付けると、管理画面で「どの投稿が効いたか」を見られます。
- X: `https://（URL）/?src=x`　／　Instagramのプロフィール: `?src=ig`　／　ストーリーズ: `?src=ig_story`
- 使える文字は半角の英数字・`_`・`-`（20文字まで）。

## 4. データの管理（パソコン上）
1. 管理画面から「回答CSV」をダウンロード（BOM付きUTF-8。Excelでも開けます）。
2. 分析: `survey_needs` フォルダで `streamlit run survey_app.py` → そのCSVを読み込む。
3. 先行案内のメールCSVは**別ファイル**です。分析には使わず、案内以外に使わない。
4. バックアップ: `survey.db` をコピー。

## 5. セキュリティ・プライバシー
- IPアドレスや端末情報は保存しません（回数制限は、起動ごとに変わる値でハッシュ化したものをメモリ上だけで使用）。
- メールアドレスは回答と別テーブル。任意入力です。
- 管理画面は `ADMIN_PASSWORD` が未設定なら存在しません（404）。パスワードは推測されにくいものにする。
  Basic認証は暗号化されないため、**必ずHTTPS（トンネル/クラウド側のHTTPS）経由**で使う。
- CSVの先頭が `= + - @` のセルは、Excelで数式として実行されないよう処理しています。
- スパム対策: 見えない入力欄（ハニーポット）と、同一端末からの送信回数制限（20回/時間）。
- 個人情報の取り扱い（プライバシーポリシー）と、勤務先の規程は、公開前に確認してください。

## 6. テスト
```
python -m unittest discover -s tests
```
必須・最大3つ選択・不正な選択肢・ハニーポット・回数制限・管理画面の認証・CSV出力・分析アプリとの互換性を確認します。
