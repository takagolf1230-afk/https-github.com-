# 放射線科 勤務表 自動作成・管理アプリ

放射線科の月間勤務表を、ルールに基づいて **自動生成（数理最適化）** し、**画面上で手動調整**、
**Excel / 印刷用PDF** で出力するローカルWebアプリです。院内PC単体（オフライン）で動作します。

| ファイル | 役割 |
|---|---|
| `app.py` | Streamlit の画面と全体制御 |
| `scheduler.py` | PuLP(CBC)による自動生成・制約チェック・競合箇所の特定 |
| `db_manager.py` | SQLite (`duty_roster.db`) の読み書き（マスタ・希望休・勤務表） |
| `exporter.py` | Excel(.xlsx) / PDF 出力（A4横1ページ） |
| `run.bat` | ダブルクリック起動用 |

## 1. セットアップ

### Python のインストール
Python 3.10 以上を入れてください（インストール時「Add python.exe to PATH」にチェック）。

### 起動
`run.bat` をダブルクリックします。初回のみ仮想環境の作成とライブラリのインストールが走り、
ブラウザで `http://localhost:8501` が開きます。以降は同じ操作で即起動します。
終了するときは黒い画面(コンソール)を閉じてください。

### 完全オフライン環境への導入
インターネットに繋がるPCで、このフォルダ内で次を実行し、できた `wheelhouse` フォルダごと院内PCへコピーします。
同じ Windows・同じ Python バージョンで作成してください。

```
pip download -r requirements.txt -d wheelhouse
```

`wheelhouse` があると `run.bat` は自動的にそこからインストールします（ネット接続不要）。
祝日判定(jpholiday)・ソルバー(CBC)も同梱ライブラリだけで動き、外部通信は一切ありません。

## 2. 操作の流れ

左サイドバーで **年・月** を選び、メニューを上から順に進めます（既定は翌月）。

### ① マスタ設定（初回のみ）
- **スタッフ**: 氏名・雇用形態・PB可/早番可/ハ番可・公休調整・有効を登録。
  「サンプルスタッフ12名を登録」で試験データも入れられます。
  表の下端で行追加、行を選択して Delete で削除。表の順番が勤務表の並び順です。
  ※PBの翌日は早番になるため、**PB担当者は「早番可」も必要**です。
- **シフト種別**: 略称・名称・始業時間・カウント単位(全日/半日/休)・色など。
  基本6種(日, PB, 早, ハ, 半, 休)の略称は変更不可。「年休」など独自シフトは行追加で登録できます。
- **必要人数**: 曜日・祝日・第3日曜ごとの PB/早番/ハ番/日勤 の最小・最大人数。最大が空欄=上限なし。
  初期値はご指定のルール（ハ番: 月火木土=2名、水金日祝=0名、第3日曜=早番1+ハ番1）です。
  優先順位は 第3日曜 ＞ 祝日(日曜以外) ＞ 曜日。
  **日勤の最小・最大は初期値が仮置き**なので、実際の人員に合わせて調整してください。
- **ルール**: 各ルールのON/OFF、連続勤務の上限日数（初期6=7連勤以上NG）。
- **月別公休数**: 選択中の月の規定公休日数（未設定の月は「土日祝の日数」を使用）。希望休も公休にカウントされます。
- **特別日(祝日)**: 年末年始など祝日扱いにしたい日の追加、祝日扱いの解除。祝日は自動判定されます。

### ② 希望休・個別予定の入力
「希望休・個別予定」で、技師×日のカレンダーに 希(希望休)/出(出張)/研(研修) を選んで保存します。
自動生成ではこの内容が固定されます。

### ③ 自動生成
「勤務表」で **⚙ 自動生成** を押します（制限時間はスライダーで変更。通常10〜30秒）。

守られるルール(ハード制約):
- PBの翌日は早番／土曜PBの翌日(日曜)は半休（前月末のPBも引き継ぎ）
- 連続勤務の上限、月間公休日数、日別の必要人数、担当可否、希望休

可能な範囲で整えるもの(ソフト制約): PB・ハ番・早番・土日祝勤務の回数の公平化、平日人数の平準化、上限ちょうどの連勤回避。

**解がない場合**は制約を緩和した暫定案を表示し、「競合している制約」に原因候補
（例: `10/5(月) PBが1名以上必要`）を一覧します。希望休や必要人数を見直してください。

前月の勤務表を保存してあると、月またぎの連続勤務・PB翌日を考慮します。

### ④ 手動調整
グリッドのセルをプルダウンで直接変更します。変更のたびにチェックが走り、
下の「チェック表示」で **違反セルが赤** になります（連続勤務超過、PB翌日の抜け、希望休の不履行、
資格のないシフト、未入力など）。「日別人数」「個別集計」も赤で過不足を示します。
調整が済んだら **💾 保存**。「保存済みを読込」で保存状態に戻せます。

### ⑤ 出力・印刷
「Excel/PDF出力」で保存済みの勤務表を **A4横1ページ** の `.xlsx` / `.pdf` でダウンロードします。
PDF の日本語は内蔵フォントを使うため、表示にはPDFビューア側の日本語フォント（Acrobat・Edge等）が必要です。

## 3. データ・バックアップ
すべて `duty_roster.db` に保存されます。このファイルをコピーすればバックアップ・PC移行ができます。

## 4. 拡張のヒント
- 制約の追加: `scheduler.py` の `_build()`（最適化）と `check_roster()`（手動チェック）に同じ内容を追加。
- 目的関数の重み: `scheduler.py` 冒頭の `W_*` 定数。
- ルールのON/OFF項目追加: `db_manager.py` の `DEFAULT_RULES` に追加（既存DBにも起動時に補完されます）。
